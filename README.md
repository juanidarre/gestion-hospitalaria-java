
# Sistema de Gestión Hospitalaria

## Descripción

Proyecto académico desarrollado en Java para la materia Programación 2 de la Tecnicatura en Programación.

El sistema representa la organización y el funcionamiento de un hospital mediante programación orientada a objetos, permitiendo administrar pacientes, médicos, departamentos, salas, historias clínicas y citas médicas.

## Funcionalidades

- Gestión de hospitales y departamentos.
- Administración de pacientes y médicos.
- Registro de historias clínicas.
- Administración de salas.
- Programación y consulta de citas médicas.
- Validación de datos de pacientes y médicos.
- Control de disponibilidad de médicos y salas.
- Manejo de excepciones personalizadas.

## Tecnologías utilizadas

- Java.
- Apache NetBeans.
- Apache Ant.

## Conceptos de programación aplicados

- Programación Orientada a Objetos.
- Herencia y polimorfismo.
- Encapsulamiento.
- Interfaces.
- Enumeraciones.
- Colecciones.
- Manejo de excepciones.
- Relaciones entre objetos.

## Estructura del proyecto

- `src/org/jcr/entidades/`: contiene las clases principales del sistema.
- `src/org/jcr/enums/`: contiene las enumeraciones utilizadas.
- `src/org/jcr/excepciones/`: contiene las excepciones personalizadas.
- `src/org/jcr/servicios/`: contiene la lógica para administrar las citas médicas.
- `src/org/jcr/MainPruebas.java`: contiene verificaciones para comprobar el funcionamiento del sistema.

## Pruebas

El proyecto incluye una clase de pruebas con 10 grupos de verificaciones que permiten comprobar diferentes funcionalidades y reglas del sistema.

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir el proyecto desde Apache NetBeans.
3. Ejecutar la clase `MainPruebas.java` para realizar las verificaciones.
